# Fabric Data

> Fabric delivers agent-ready data, metadata, and operations software for media and entertainment. Two product families: Xytech (media operations ERP: scheduling, media orders, transmission) and Origin (Studio: metadata source of truth; Nexus: enrichment APIs; Insights: market intelligence). All product lines expose MCP servers with OAuth-governed access — each agent identity's permissions determine which tools it can use — plus REST APIs with machine-readable schemas and documentation published for agent consumption.

## MCP Servers (agent execution surfaces)

- [Xytech X2 MCP](https://knowledgebase.fabricdata.com/xytech/xytech-x2-mcp-server): Orders, media workflows, resource scheduling, transmission. OAuth, tool-level scoping.
- [Origin Studio MCP](https://knowledgebase.fabricdata.com/studio/origin-studio-mcp-server): Unified server spanning Origin Studio and Nexus. Metadata records, catalog operations, availability. OAuth rights dictate tool access.
- [Origin Insights MCP](https://knowledgebase.fabricdata.com/insights/origin-insights-mcp): Market intelligence: streaming availability, pricing & plans, demand, Pay TV, consumer surveys. OAuth-based, usage-based consumption.
